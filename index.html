Rotate through circles of IPs, and spend where it converts

One product, a fixed number of impressions a day, and an audience of IP addresses grouped into circles, like subnets or areas. Nearby circles tend to behave alike, and showing the same IP again too soon works less well. This page simulates whether rotating through the circles, following the hot ones and resting the misses cuts wasted impressions.

The strategies

  1. Random blast. Each day, random IPs that haven't bought yet. This is the baseline.
  2. Even rotation. One fixed loop through every IP, circle by circle. Nobody sees the ad again until everyone has seen it once.
  3. Follow hot circles. Each day's budget goes out in small chunks to the circles selling best so far. A circle's neighbours count as half-evidence, so one hot circle warms up those around it. Cold circles fade out.
  4. Hot circles + retry loop. The same, but an IP that just saw the ad rests until its fatigue wears off, then rejoins its circle's loop. This combines all three ideas.
  5. Perfect knowledge. Knows every IP's true rate and shows the best rested IPs first. It's a ceiling, not something you can run.

All strategies spend the same budget on the same simulated audiences, and learn only from circle-level totals. The same engine runs in Python from the repo: python -m prisoners --help.

Every strategy runs on the same audiences, so the differences come from the strategy alone.
